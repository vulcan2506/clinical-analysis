# transgender GFR estimation
*Source: Chronic Kidney Disease.pdf*

**Clinical Recommendation:** transgender GFR estimation and reporting

**Clinical Actions:**
- Use a shared decision-making approach with the person with CKD, considering muscle mass, sex hormone milieu, sex assigned at birth, and gender identity for eGFR evaluation.
- Report eGFR in addition to serum concentrations of filtration markers using validated equations.
- Report eGFR rounded to the nearest whole number relative to a body surface area (BSA) of 1.73 m² in adults using units ml/min per 1.73 m².
- Flag reported eGFR levels <60 ml/min per 1.73 m² as low.
- Measure filtration markers using specific, precise assays with calibration traceable to international standards and desirable bias.

**Patient Eligibility Criteria:**
- Use enzymatic method to assay creatinine where possible.
- Separate serum/plasma from red blood cells by centrifugation within 12 hours of venipuncture.
- When cystatin C is measured, measure creatinine on the same sample to enable calculation of eGFRcr-cys.
- Report serum creatinine (SCr) concentration rounded to the nearest whole number when expressed as standard international units (µmol/l) and to the nearest 100th of a whole number when expressed as conventional units (mg/dl)
- Report serum cystatin C concentration rounded to the nearest 100th of a whole number when expressed as conventional units (mg/l)
- Measure filtration markers using assays with coefficient of variation (CV) <2.3% for creatinine and <2.0% for cystatin C, and desirable bias (<3.7% for creatinine and <3.2% for cystatin C) compared with reference methodology
