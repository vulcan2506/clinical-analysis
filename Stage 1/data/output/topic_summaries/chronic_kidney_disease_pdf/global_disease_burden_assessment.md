# global disease burden assessment
*Source: Chronic Kidney Disease.pdf*

**Clinical Recommendation:** global disease burden assessment in CKD using GBD framework

**Clinical Actions:**
- Assesses impact of CKD using Global Burden of Disease (GBD) framework
- Measures premature death and disability from CKD across 204 countries
- Includes data by age and sex from 1990 to present
- Evaluates burden through metrics like DALYs (Disability-Adjusted Life Years)
- Aggregates data from over 350 diseases and injuries
- Uses GBD framework to compare CKD burden across countries and regions
- Assesses CKD burden trends over time using GBD data

**Patient Eligibility Criteria:**
- Standardized data collection across multiple countries
- Longitudinal tracking from 1990 to present
- Age- and sex-stratified analysis
- Integration of mortality and disability metrics
- Use of GBD methodology for comparability
- Ensures comparability of CKD burden estimates across countries through GBD methodology
- Incorporates GBD risk factor attribution for CKD (e.g., hypertension, diabetes)
