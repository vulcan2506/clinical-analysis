# evidence certainty grading framework
*Source: Chronic Kidney Disease.pdf*

**Clinical Recommendation:** evidence certainty grading framework (GRADE)

**Clinical Actions:**
- Grading of Recommendations Assessment, Development, and Evaluation (GRADE) framework used to assess certainty of evidence for critical outcomes.
- Initial certainty grade for RCTs is 'High' (Grade A), lowered based on study limitations, inconsistency, indirectness, imprecision, or publication bias.
- Certainty grades: A (High), B (Moderate), C (Low), D (Very Low).
- Heterogeneity assessed via χ² test (α ≤ 0.10) and I² statistic (>50% indicates substantial heterogeneity).
- Imprecision evaluated using optimal information size, event rates, CIs (25% decrease/increase threshold), and sparse data.
- Assessment of heterogeneity includes evaluation of variability in effect estimates due to heterogeneity (I² statistic) rather than random chance, with >50% indicating substantial heterogeneity.

**Patient Eligibility Criteria:**
- Critical outcomes must be assessed for certainty of evidence using GRADE approach.
- Initial high certainty for RCTs requires evaluation of study limitations, inconsistency, indirectness, imprecision, and publication bias.
- Heterogeneity thresholds (χ² α ≤ 0.10, I² >50%) must be applied to trial data.
- Imprecision benchmarks (optimal information size, event rates, CIs, sparse data) must be considered.
- Summary of Findings (SoF) tables must include population, intervention, comparator, and graded certainty for each outcome.
- Data benchmarking for imprecision includes low event rates in either arm, CIs indicating appreciable benefit and harm (25% decrease/increase thresholds), and sparse data (only 1 study) as explicit criteria for lowering certainty grades.
