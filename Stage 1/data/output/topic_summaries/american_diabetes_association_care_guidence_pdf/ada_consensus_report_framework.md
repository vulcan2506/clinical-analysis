# ADA consensus report framework
*Source: American Diabetes Association Care Guidence.pdf*

**Clinical Recommendation:** ADA consensus report framework

**Core Recommendations:**
- Authored by a technical expert panel under ADA auspices
- Provides clarity on diabetes-related topics with contradictory, emerging, or incomplete evidence
- Highlights evidence gaps and proposes future research avenues
- Undergoes formal review including external peer review and ADA PPC/scientific team review
- Does not reflect official ADA position but represents expert consensus

**Patient Eligibility Criteria:**
- Expert panel composition for topic-specific technical analysis
- Formal review process involving external peers and ADA scientific teams
- Collaboration with partner organizations for joint consensus reports
- Rigorous development phases from initiation through publication
- Focus on emerging or controversial diabetes care areas

**Updated Recommendations:**
- Joint consensus report framework with partner organizations
- Explicit inclusion of evidence gap identification in reports
- Structured external peer review process for consensus reports
