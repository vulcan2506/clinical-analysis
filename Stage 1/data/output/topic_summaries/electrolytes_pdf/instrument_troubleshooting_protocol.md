# instrument troubleshooting protocol
*Source: electrolytes.pdf*

**Test Method:** instrument troubleshooting protocol for electrolyte testing

**Performance Characteristics:**
- Check hardware functionality first
- Recalibrate the instrument if issues persist
- Verify reference material integrity
- Consult supervisor for unresolved QC failures
- Contact Roche hotline or service engineer if needed

**Pre-analytical Requirements:**
- Ensure QC materials are within statistical control before reporting results
- Follow escalation steps in order (hardware → calibration → reference → supervisor → service)
- Ensure QC materials are within statistical control before proceeding with testing
