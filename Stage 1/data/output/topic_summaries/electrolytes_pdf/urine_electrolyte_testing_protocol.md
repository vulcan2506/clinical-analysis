# urine electrolyte testing protocol
*Source: electrolytes.pdf*

**Test Method:** urine electrolyte testing protocol (Sodium, Potassium, Chloride)

**Performance Characteristics:**
- Uses Roche Ion-Selective Electrode method for testing Sodium, Potassium, and Chloride in urine.
- Specimens are collected and tested as part of NHANES 2014 protocol.
- Users must verify method revisions with the listed contact before use.
- Document acknowledges periodic refinements by CDC to laboratory methods.
- Uses NHANES 2014 protocol for urine electrolyte collections (MEC Collection)
- Acknowledges contributions from Donna LaVoie and Christine Pfeiffer in assay evaluation and manuscript preparation

**Pre-analytical Requirements:**
- Specimens must be collected and handled according to NHANES 2014 protocol.
- Method No. 4047.03 must be followed for accurate testing.
- Contact listed (James L. Pirkle, M.D., Ph.D.) for method updates before use.
- Specimens must be collected as part of NHANES 2014 MEC Collection protocol
- Users must verify method revisions with James L. Pirkle, M.D., Ph.D. before use
