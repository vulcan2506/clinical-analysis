# ion selective electrode measurement system
*Source: electrolytes.pdf*

**Test Method:** Ion-Selective Electrode (ISE) measurement system

**Performance Characteristics:**
- Uses liquid/liquid junction type ISE with reference electrode and electronic circuits to measure EMF and determine ion concentration
- Sodium and potassium electrodes are based on neutral carriers
- Chloride electrode is based on an ion exchanger
- Sample is diluted 1:31 with a single 15 µL sample used for three assays
- Electronic circuits process EMF to calculate ion concentration using Nernstian response equations

**Pre-analytical Requirements:**
- Reference electrode must be maintained with consistent electrolyte fill (e.g., KCl solution) to ensure stable junction potential
