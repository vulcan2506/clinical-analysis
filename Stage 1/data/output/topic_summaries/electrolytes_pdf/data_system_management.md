# data system management
*Source: electrolytes.pdf*

**Test Method:** data system management for electrolyte testing

**Performance Characteristics:**
- The Hitachi Modular PE Control Module is used to review data and check for samples that need to be diluted or repeated for confirmation.
- The LIMS database is used for additional levels of data review by the analyst, project lead, QA officer, and supervisor.
- The LIMS database is used for data reporting.
- The system can be completely turned off for the weekend or extended holidays.
- The system can be turned off when indicated by maintenance procedure or error code.
