# electrolyte reference ranges
*Source: electrolytes.pdf*

**Test Method:** electrolyte reference ranges

**Performance Characteristics:**
- Serum and plasma sodium (Na+) reference range: 133-145 mmol/L
- Serum potassium (K+) reference range: 3.3-5.1 mmol/L; plasma K+: 3.3-4.5 mmol/L
- Serum and plasma chloride (Cl-) reference range: 96-108 mmol/L
- Urine (24-hour) sodium (Na+) reference range: 40-220 mmol/day (diet dependent)
- Urine (24-hour) potassium (K+) reference range: 25-125 mmol/day (diet dependent)

**Pre-analytical Requirements:**
- Reference ranges for serum and plasma electrolytes were established from a study of 4,610 normal, healthy adults
- Urine electrolyte reference ranges are diet dependent and vary by age group
- Urine electrolyte reference ranges vary by age group (e.g., neonates, infants, children)
