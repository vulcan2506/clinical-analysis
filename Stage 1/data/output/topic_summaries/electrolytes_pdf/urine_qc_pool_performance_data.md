# urine QC pool performance data
*Source: electrolytes.pdf*

**Test Method:** urine QC pool performance data for sodium, potassium, and chloride

**Performance Characteristics:**
- QC pool performance data must be tracked for sodium, potassium, and chloride in urine collections
- Mean, standard deviation, and coefficient of variation (CV) values are recorded for each QC lot
- Acceptable CV ranges are typically below 3.8% for low-level controls and below 2.9% for high-level controls
- Data spans specific date ranges (e.g., 04FEB14 to 19FEB15 for CC2_URCL5H1)
- Sample sizes (N) for QC pools range from 11 to 49 measurements

**Pre-analytical Requirements:**
- QC pool data must be reviewed before reporting patient results to ensure system performance
- Mean values must align with expected concentrations for each analyte and lot
- Standard deviation and CV must meet predefined acceptance criteria for each lot
- Data collection must cover the full reporting period for accurate trend analysis
- Unacceptable QC results require corrective action before proceeding with testing
- QC pool data must include mean, standard deviation, and CV values for each analyte (sodium, potassium, chloride) separately, not just combined
- QC lot performance must be evaluated against NHANES 2014 compliance standards for urine electrolyte testing
