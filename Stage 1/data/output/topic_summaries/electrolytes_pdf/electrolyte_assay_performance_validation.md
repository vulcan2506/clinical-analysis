# electrolyte assay performance validation
*Source: electrolytes.pdf*

**Test Method:** electrolyte assay performance validation (Roche ISE Plus)

**Performance Characteristics:**
- Bias for sodium <5% over 12.4-198.7 mmol/L using NIST reference material
- Bias for chloride <7% over 24.8-198.7 mmol/L using NIST reference material
- Negative bias for potassium <14% over 3.68-99.4 mmol/L using NIST reference material
- Within-day imprecision <1% for urine sodium, <3.6% for urine potassium, <2.2% for urine chloride (n=10)
- Between-day imprecision <3% for urine sodium, <6.5% for urine potassium, <3% for urine chloride (n=57 days)

**Pre-analytical Requirements:**
- Dilution linearity must achieve r² > 0.999
- Measured concentrations must be within ±10% of expected concentrations
- LOD determined in-house using GEN1 reagents: 4 mmol/L (Na), 0.2 mmol/L (K), 0.4 mmol/L (Cl)
- Measured concentrations must correspond within ±10% of expected concentrations using Validate UC1 urine material
