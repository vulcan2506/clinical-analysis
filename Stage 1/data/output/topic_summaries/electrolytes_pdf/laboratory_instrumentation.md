# laboratory instrumentation
*Source: electrolytes.pdf*

**Test Method:** laboratory instrumentation

**Performance Characteristics:**
- Utilizes the MODULAR ANALYTICS E170® system for electrolyte analysis
- Employs Daigger Vortex Genie 2 for specimen mixing
- Uses Eppendorf micropipets and tips for precise liquid handling

**Pre-analytical Requirements:**
- Instrument must be the MODULAR ANALYTICS E170® system
- Vortex mixer must be the Daigger Vortex Genie 2 model
- Pipetting must utilize Eppendorf brand micropipets and tips
- Instrument must be calibrated using Roche Diagnostics-provided calibration materials for the MODULAR ANALYTICS E170® system
