# instrumentation setup protocol
*Source: electrolytes.pdf*

**Test Method:** instrumentation setup protocol

**Performance Characteristics:**
- Allow patient samples, calibrators and QC to reach ambient temperature before testing.
- Ensure adequate reagent volume for the number of samples to be analyzed.
- Verify that the analyzer and required tests are not masked or disabled.
- Check calibration status and perform calibration if required for the tests to be run.
- Set the default profile via the 'Start' global button if running the same tests on all samples.
- Perform the required maintenance on the ISE Module.

**Pre-analytical Requirements:**
- Patient samples, calibrators, and QC must reach ambient temperature before analysis.
- Reagent volume must be sufficient for the planned sample batch.
- Analyzer and tests must be unmasked and operational.
- Calibration must be performed if required for the selected tests.
- Previously programmed samples must be cleared from the Data Review screen after data backup.
