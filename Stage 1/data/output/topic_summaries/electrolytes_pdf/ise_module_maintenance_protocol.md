# ISE module maintenance protocol
*Source: electrolytes.pdf*

**Test Method:** ISE module maintenance protocol

**Performance Characteristics:**
- Daily maintenance must be performed at the start of each 8-hour shift or more frequently if necessary
- Run the 'green rack' to clean and condition the ISE module after all sampling is completed for the day
- Maintenance includes daily, weekly, and as-needed procedures

**Pre-analytical Requirements:**
- Refer to instrument maintenance logs for additional maintenance requirements
- Follow step-by-step instructions in the Roche Modular Analytics® Operator's Manual for detailed procedures
