# quality control data
*Source: electrolytes.pdf*

**Test Method:** quality control data for urine electrolytes in NHANES 2014

**Performance Characteristics:**
- Analyzes lot-specific QC data for urine sodium, potassium, and chloride with mean, standard deviation, and coefficient of variation (CV) metrics
- Tracks QC performance across multiple reagent lots (e.g., URCA6H1, URCA5H1, CC2_URCM5H1) with consistent CV thresholds (e.g., 1.7% to 6.0%)
- Uses Levey-Jennings charts (e.g., img-0.jpeg, img-1.jpeg) to visualize QC trends and detect shifts or trends in analyte measurements
- Validates QC data against predefined acceptance criteria (e.g., CV < 6.0%) to ensure analytical reliability
- Incorporates NHANES 2014 study-specific QC protocols for urine electrolyte measurements
- Tracks QC performance across reagent lots with varying sample sizes (e.g., N=30 for low controls vs. N=66 for medium/high controls)
- Documents lot-specific QC data with start and end dates for reagent usage periods (e.g., URCA6H1: 29JAN14–18FEB15)

**Pre-analytical Requirements:**
- Adherence to NHANES 2014 QC protocols for urine electrolyte testing
- Use of lot-specific QC materials with documented mean, SD, and CV values
- Regular review of Levey-Jennings charts to monitor QC performance
- Maintenance of QC records for at least the duration of reagent lot usage
- Compliance with acceptance criteria (e.g., CV ≤ 6.0%) for QC data
- QC acceptance criteria must account for analyte concentration levels (e.g., stricter CV thresholds for low-concentration controls)
- QC records must include sample size (N) for each lot to assess statistical reliability of mean/SD/CV calculations
