# calibration standards
*Source: electrolytes.pdf*

**Test Method:** calibration standards for electrolyte testing

**Performance Characteristics:**
- Standards are available from Roche Diagnostics in liquid form, ready to use.
- An internal standard solution is measured during calibration and between each sample to correct the calibration for drift between calibrations.
- The standards are stored at room temperature and are stable until the expiration date on the box.

**Pre-analytical Requirements:**
- Use ISE Standard Low (Cat. No. 11183974 216, Code 502) for calibration.
- Use ISE Standard High (Cat. No. 11183982 216, Code 503 or Code 763) for calibration.
- Calibration must be performed using both ISE Standard Low (Code 502) and ISE Standard High (Code 503 or Code 763) for accurate electrolyte measurement.
