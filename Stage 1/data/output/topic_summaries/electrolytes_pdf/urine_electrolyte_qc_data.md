# urine electrolyte QC data
*Source: electrolytes.pdf*

**Test Method:** urine electrolyte QC data analysis and reporting

**Performance Characteristics:**
- QC data must include Lot, N (sample size), Start Date, End Date, Mean, Standard Deviation, and Coefficient of Variation for each reagent lot
- Coefficient of Variation (CV) must be calculated and reported for all electrolyte measurements (Sodium, Potassium, Chloride)
- QC data must be reviewed for consistency across reagent lots and time periods
- CV values should generally remain below 3.0% for acceptable performance, with specific lot-based thresholds
- QC data must be documented in NHANES 2014 compliance format with standardized reporting structures

**Pre-analytical Requirements:**
- QC data must be collected over a minimum of 48 samples (N ≥ 48) for high-range lots
- QC data must be collected over a minimum of 21 samples (N ≥ 21) for low-range lots
- QC data must cover a defined time period (e.g., 4FEB14 to 19FEB15 for most lots)
- Mean values must fall within expected physiological ranges for urine electrolytes
- Standard deviation must not exceed predefined thresholds for each analyte and lot
- QC data must include Start Date and End Date for each lot to ensure time-bound validation of reagent performance
- Mean values must be reported with at least two decimal places for precision in low-range controls (e.g., 6.00, 22.964)
