# sharps disposal protocol
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** sharps disposal protocol

**Therapeutic Actions:**
- Dispose of used needles in a bio-safe manner
- Collect used sharps in a strong cardboard or glass container
- Seal and label the sharps container
- Hand over sealed sharps container to the nearest healthcare facility

**Prerequisites:**
- Use a strong cardboard or glass container specifically designed for sharps disposal
