# institutional header
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** institutional header formatting and consistency

**Therapeutic Actions:**
- Use standardized institutional header format for official communications
- Include both English and Hindi (स्वास्थ्य अनुसंधान विभाग) versions for official documents
- Maintain consistent address format: Department name, Ministry name, building name, area, city, PIN code, and country
- Ensure uniformity in spacing and punctuation (e.g., hyphen in 'New Delhi - 110 029')
- Repeat full institutional details in multi-section documents for clarity
- Include '(भारत)' in Hindi address format alongside the PIN code
- Ensure consistent spacing in Hindi address (e.g., 'नई दिल्ली - 110 029' vs 'नई दिल्ली-110029')

**Prerequisites:**
- Must include both English and Hindi department names for official Indian government communications
- Address must include V. Ramalingaswami Bhawan, Ansari Nagar, New Delhi, and PIN code 110029
- Ministry name must include both 'Department of Health Research' and 'Ministry of Health & Family Welfare'
- Official documents must display the complete institutional header at the top
- Consistent formatting must be maintained across all official communications
- Hindi department name must be 'स्वास्थ्य अनुसंधान विभाग' without additional modifiers
- English ministry name must be 'Ministry of Health & Family Welfare' (with ampersand)
