# ADA Standards of Care framework
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** ADA Standards of Care screening framework

**Therapeutic Actions:**
- Screening for diabetes should preferably be conducted in a healthcare setting
- Community screening is an acceptable alternative if healthcare setting screening is not feasible
- Screening should be performed using standardized diagnostic criteria (e.g., HbA1c, FPG, or 2-h PG after 75-g OGTT)

**Prerequisites:**
- Screening should be performed in a setting that ensures follow-up care and diagnostic confirmation
- Community screening programs must have protocols for referral to healthcare providers for confirmatory testing and follow-up
- Screening should be conducted in a setting with trained personnel capable of performing and interpreting diagnostic tests
- Community screening programs must ensure access to confirmatory testing within a defined timeframe (e.g., 2 weeks)
