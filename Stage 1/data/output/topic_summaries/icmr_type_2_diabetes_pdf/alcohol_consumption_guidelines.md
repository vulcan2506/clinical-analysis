# alcohol consumption guidelines
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** alcohol consumption in type 2 diabetes

**Therapeutic Actions:**
- Avoid alcohol consumption if possible
- If alcohol is consumed, take it in moderation
- Do not count alcohol as part of the meal plan
- Monitor for hypoglycemia in the fasting state
- Be aware that alcohol provides 7 kcal/g of empty calories
- Avoid alcohol if you have advanced liver disease, neuropathy, or dyslipidaemia
- Avoid alcohol if you are pregnant or planning pregnancy

**Prerequisites:**
- Assess liver function (ALT, AST, GGT) and lipid profile before advising alcohol consumption
