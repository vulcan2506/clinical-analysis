# sweetener use guidelines
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** sweetener use guidelines

**Therapeutic Actions:**
- Avoid nutritive sweeteners (e.g., fructose, honey, corn syrup, molasses, fruit juice concentrates, dextrose, maltose, mannitol, sorbitol, xylitol)
- Use non-nutritive sweeteners (e.g., aspartame, acesulfame K, stevia, sucralose, saccharin) in moderation
- Avoid non-nutritive sweeteners during pregnancy
