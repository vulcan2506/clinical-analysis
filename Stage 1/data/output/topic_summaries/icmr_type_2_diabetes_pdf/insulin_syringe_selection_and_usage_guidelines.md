# insulin syringe selection and usage guidelines
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** insulin syringe selection and usage guidelines

**Therapeutic Actions:**
- Use syringes marked in insulin units (U-40 or U-100) for subcutaneous insulin administration
- Ensure syringe-vial concentration match (U-40 syringe for U-40 insulin, U-100 syringe for U-100 insulin)
- Prefer fixed needle (single unit) syringes for conventional insulin administration
- Never share syringes or needles with another person
- Recap needles carefully after each use if reuse is planned; avoid wiping or washing needles
- Use fixed needle (single unit) syringes for conventional insulin administration

**Prerequisites:**
- Syringe concentration must match insulin vial concentration to prevent dosing errors
