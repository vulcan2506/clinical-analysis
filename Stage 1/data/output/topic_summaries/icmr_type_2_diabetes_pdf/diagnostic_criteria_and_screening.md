# diagnostic criteria and screening
*Source: ICMR Type 2 Diabetes.pdf*

**Clinical Recommendation:** diagnostic criteria and screening for type 2 diabetes

**Therapeutic Actions:**
- Use standard diagnostic criteria for type 2 diabetes based on symptoms and laboratory tests
- Apply specific criteria for diagnosing prediabetes
- Perform Oral Glucose Tolerance Test (OGTT) when indicated
- Screen children and adolescents for type 2 diabetes using targeted criteria
- Use HbA1c as an alternative diagnostic criterion for type 2 diabetes when fasting plasma glucose or OGTT is impractical
- Screen high-risk adults (e.g., those with BMI ≥23 kg/m², hypertension, or family history) annually for type 2 diabetes
- Perform random plasma glucose testing in symptomatic individuals to support diagnosis

**Prerequisites:**
- Symptoms of diabetes must be evaluated alongside laboratory confirmation
- Prediabetes diagnosis requires adherence to defined glycemic thresholds
- OGTT must be conducted following standardized protocols
- Screening in children/adolescents should follow pediatric-specific guidelines
- HbA1c testing must be performed using NGSP-certified methods standardized to the DCCT assay
- Prediabetes diagnosis requires confirmation with a second test (fasting glucose, OGTT, or HbA1c) on a different day unless unequivocal hyperglycemia is present
- Screening in children/adolescents should prioritize those with BMI ≥85th percentile for age/sex or with additional risk factors (e.g., family history, acanthosis nigricans)
