# Imaging for Metastatic Detection
*Source: American Thyroid Association.pdf*

**Clinical Recommendation:** Imaging for Metastatic Detection

**Key Clinical Findings:**
- Preoperative imaging with ultrasound and CT is recommended for all primary and reoperative thyroid cancer patients to map nodal disease.
- F-18 FDG PET/CT is prioritized for preoperative lymph node staging in high-risk differentiated thyroid cancer patients.
- MRI is considered for detecting metastatic cervical lymph nodes when ultrasound is inconclusive.
- Contrast-enhanced CT should not delay radioiodine ablation in differentiated thyroid carcinoma patients.
- Preoperative iodinated contrast agents require a one-month wait before radioiodine therapy to allow urinary iodine to normalize.

**Patient Eligibility Criteria:**
- Patient must have confirmed differentiated thyroid cancer diagnosis.
- High-risk features (e.g., extrathyroidal extension, nodal metastases) necessitate advanced imaging.
- Radioiodine therapy candidates must have baseline urinary iodine levels assessed post-contrast use.
