# Clinical Care Fundamentals (13)

This topic establishes standardized quality control (QC) acceptance criteria for electrolyte testing in clinical laboratories, ensuring analytical reliability and patient safety through rigorous evaluation of QC specimen results.

**Key Features:**
- Duplicate analysis of commercially prepared QC specimens per run to verify consistency
- Run acceptance based on QC run means within 2 standard deviations (2Sm) and individual results within 2 standard deviations of individual results (2Si)
- Run rejection triggered by QC run mean outside 2Sm limit, invoking 3S, 2S, or 10 X-bar rule for error detection

**Notable Details:**
- QC specimens are analyzed in duplicate per run to ensure reproducibility
- Run acceptance requires both QC run means to be within 2Sm limits for validation
- Individual QC results must be within 2Si limits for run acceptance to confirm precision
- Run rejection occurs if one QC run mean is outside 2Sm limit, prompting further investigation
- 3S, 2S, or 10 X-bar rules are applied upon run rejection to identify systematic errors
- Electrolyte testing-specific QC criteria ensure analytical accuracy for critical analytes
- Commercially prepared QC specimens standardize testing conditions across laboratories
- QC evaluation focuses on both run-level and individual result-level deviations to maintain quality

**Test Method:** quality control acceptance criteria for electrolyte testing

**Performance Characteristics:**
- Commercially prepared QC specimens are analyzed in duplicate per run.
- Run is accepted if both QC run means are within 2Sm limits and individual results are within 2Si limits.
- Run is rejected if one QC run mean is outside 2Sm limit and triggers 3S, 2S, or 10 X-bar rule.
- Run is rejected if one of four individual QC results is outside 2Si limit and triggers Extreme Outlier or R 4S rule.
- QC results are checked after each run using a multi-rule quality control program.
- QC results are checked after each run using a multi-rule quality control program [10]

**Pre-analytical Requirements:**
- Two QC pools per run with two or more QC results per pool must be analyzed.
- Initial QC limits are established by analyzing pool material in 20 consecutive runs.
- QC limits are reevaluated periodically and updated when necessary.
- QC results must be stored in LIMS database for study runs or in analyte-specific network folders for non-database runs.
- Hardcopy of QC results from each run must be maintained by the analyst.
- No results for a given analyte are to be reported from an analytical run that has been declared 'out of control' for that analyte as assessed by internal (bench) QC.
